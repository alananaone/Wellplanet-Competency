# 好好星球文化基金會 360 年中成長評估系統

## 核心功能與特色

### 1. 評主管模組（支援 Cmd+P 列印為高規格 PDF 報告）
* **一鍵 PDF 導出**：支援瀏覽器快捷鍵 `Cmd + P` 或點擊介面上的「列印 / 存為 PDF」，內建完整 `@media print` 專屬樣式，自動過濾非必要介面按鈕，並維持報表標題、數據卡片、圖表與表格的優雅分頁排版。
* **整體評分與極值分析**：
  * **整體評分平均**（滿分 10 分）與 **NPS 推薦平均**。
  * **表現最好項目 (Top 3)**：自動計算平均得分最高之題項與最高給分。
  * **相對待提升項目 (Growth Opportunities)**：自動找出相對得分最低之題項與最低給分。
* **各題項逐題統計表**：列出全部 16 個題目（日常賦能、指導引導、跨部門推動、四大文化實踐等）之「平均得分」、「最好給分」、「最差給分」與「所有給分明細」。

### 2. 員工專用「同儕匿名回饋表」（逐題明細）
* 針對全體 9 位員工夥伴（何維安、姚品瑄、張芳媐、戴佑珍、林文琇、胡喻翔、薛筑瑄、陳泳璇、張希慈）各自生成獨立的同儕回饋明細表。
* 完全匿名化（去識別化為同儕 A、同儕 B...）。
* 涵蓋 13 題協作、工作品質、文化實踐之個別給分與平均分，並整合三大質化回饋（提升建議、其他評價、星光感謝詞）。

### 3. 主管評部屬（含缺值標註）
* 完整建立組織管理架構（張希慈、何維安、姚品瑄、董事會）。
* 各職位專屬職能對照部屬自評實例，未填答之處清楚標註柔黃色 `【待主管評核】`、`【待主管回饋】` 與 `【待設定下一步目標】`，並內嵌 `L1~L5` 下拉選單。

### 4. 全彩 ExcelJS 客戶端導出引擎
* 網頁端點擊任何 Excel 下載按鈕，皆透過 **ExcelJS** 即時在瀏覽器動態生成保留 100% Pantone 莫蘭迪柔和色系（`#F4CCCC` 珊瑚粉、`#FCE5CD` 杏桃粉、`#E4ECD3` 柔綠色）、儲存格跨欄置中、細邊框與原生下拉選單的完整 `.xlsx` 檔案。

## 快速使用方式

1. **開啟視覺化儀表板**：
   * 直接用瀏覽器（Chrome / Safari / Edge）開啟根目錄下的 `index.html`。
2. **切換主管與列印 PDF**：
   * 進入「評主管」頁籤，選取指定主管（例如：張希慈），按下鍵盤 `Cmd + P`，選擇「另存為 PDF」即可獲得完整專業報告。
3. **重新整理或上傳最新問卷**：
   * 將最新匯出的 Google 表單 CSV 檔案直接拖曳至網頁頂部，系統即自動重新計算所有維度統計與圖表。
